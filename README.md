# Antigravity Dynamic Wallpapers

> 两款专为深色 AI 工作台 / IDE 打造的 **60fps 零依赖 HTML5 Canvas 动态背景**，兼顾克制科技美学与代码阅读清晰度。
>
> Two zero-dependency, 60fps interactive HTML5 Canvas dynamic wallpapers crafted for dark-mode AI workspaces and IDEs.

---

## 包含方案 / Included Wallpapers

### 1. Aether Arch — 反重力光谱弧 (`wallpapers/aether-arch.html`)
- **灵感**：借鉴 Google Antigravity 跃升拱弧轮廓与蓝 / 绿 / 金 / 红四色光谱，转化为多层叠加的全息能量丝带。
- **动态细节**：底座扁平透视反重力引力波纹、向上飘散的微光粒子与近距星链连线、双倾角彗尾轨道信标、全息扫描微网格与鼠标视差响应。
- **护眼构图**：视觉重心位于右侧，左侧与中上部保持大面积低噪点深色留白，不干扰对话文字与代码块阅读。

### 2. Quantum Horizon — 量子脉动矩阵 (`wallpapers/quantum-horizon.html`)
- **风格**：100% 独立原创深色强科技风格（深钴蓝 / 电光青 / 冰银紫）。
- **动态细节**：3D 透视量子波动地形网格、沿网格路径穿梭的高速数据光脉、垂直全息信号光束、右上悬浮三轴全息陀螺星环、核心区微显六边形蜂窝光栅与底部实时示波器波形。

## 在线预览与使用方式 / Usage

### 1. 直接浏览器全屏体验 / Online Preview (GitHub Pages)
- 直接双击打开根目录的 [`index.html`](index.html)（或在 GitHub 仓库 `Settings → Pages` 中启用 `main` 分支根目录部署），即可在线切换两套动态壁纸、调节科技强度与速度、开启「模拟界面遮罩」测试文字可读性，并支持一键录制 **6 秒 60fps `.webm` 动态视频**。

### 2. 用作桌面 / 软件动态壁纸
`wallpapers/` 目录下的两个文件均为**单文件零依赖全屏版**，可直接用于：
- **Wallpaper Engine**：打开壁纸 → 从文件打开 → 选择 `wallpapers/aether-arch.html` 或 `wallpapers/quantum-horizon.html`
- **Lively Wallpaper**：添加壁纸 → 拖入对应 `.html` 文件
- **导出视频素材**：在 `index.html` 预览页点击「录制 6 秒 (.webm)」导出视频文件，用于支持视频背景的客户端或主题扩展。
